## 🎨 Öne Çıkan Özellikler

- 🌌 **Glassmorphism UI & Aura Glow**: Yumuşak cam efektli kart tasarımları ve canlı fare takip aura efekti.
- 🎨 **Dinamik Tema Seçici**: Navbar üzerinden anında **Zümrüt (Emerald)**, **Safir (Sapphire)**, **Amortis (Amethyst)** ve **Kehribar (Amber)** renk temaları arasında geçiş yapabilme.
- ✒️ **Lacivert Kontürlü Tipografi**: Harflerin etrafında siyah parlak şerit/kontür efektiyle zenginleştirilmiş özel isim tasarımı.
- 🛠️ **Canlı Profil Düzenleyici (Live Customizer)**: Navbardaki *"Düzenle"* butonu üzerinden isim, unvan, biyografi ve iletişim bilgilerini tarayıcıda canlı olarak güncelleyebilme ve `localStorage` ile saklayabilme.
- 🎓 **Sakarya Anadolu Lisesi & Eğitim Zaman Çizelgesi**: Kategori filtreli (Tümü, Deneyim, Eğitim, Başarılar) kariyer ve eğitim dikey zaman çizgisi.
- 📱 **Tam Responsive Mimari**: Mobil, tablet ve masaüstü ekranlar için optimize edilmiştir.

## 🚀 Hızlı Başlangıç

### 1. Yerel Olarak Çalıştırma
Projeyi bilgisayarınıza klonladıktan veya indirdikten sonra `index.html` dosyasını tarayıcınızda açmanız yeterlidir.

Alternatif olarak Python ile yerel HTTP sunucusu başlatabilirsiniz:
```bash
python -m http.server 8080
```
Tarayıcınızdan `http://localhost:8080` adresine giderek projeyi test edebilirsiniz.

---

## 🌐 GitHub Pages Üzerinde Yayınlama (Deployment)

1. Projeyi GitHub üzerinde yeni bir depoya (repository) push edin.
2. Reponun **Settings -> Pages** sekmesine gidin.
3. **Source** kısmını `Deploy from a branch` yapın ve `main` branch'ini seçin.
4. **Save** butonuna tıklayın. Web siteniz birkaç dakika içinde `https://<kullanici-adi>.github.io/<repo-adi>/` adresi üzerinden ücretsiz yayınlanacaktır!
